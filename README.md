# La Tcheam Forum

A web forum developed in Go with an SQL database, allowing users to create posts, comment, and interact via a like/dislike system.

##  Features

-  Authentication system (registration/login)
-  Post creation and display
-  Comment system
-  Like and dislike system
-  Post filtering (all posts, my posts, liked posts)

##  Technologies used

- Go (backend)
- SQLite (database)
- HTML/CSS (frontend)
- JavaScript (interactivity)
